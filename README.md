# Farhad Hasan Sabuj — Portfolio

Personal portfolio of Farhad Hasan Sabuj, Visa Consultant (Tasheel Center, Sharjah, UAE).

Static site, no build step needed. Fonts are self-hosted in `assets/fonts`.

## Publish on GitHub Pages
1. Upload everything in this folder (index.html, robots.txt, README.md, assets/) to a new repository.
2. Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
3. After 1–2 minutes the site is live at `https://<username>.github.io/<repo-name>/`.
